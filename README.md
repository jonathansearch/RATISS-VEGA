## 🌟 What is VEGA?

**RATISS VEGA** is the evolution of **RATISS-X (The LLM Mixer)** — from *thinking in paths* to *thinking in constellations*.

| Generation | Codename | Breakthrough | Limitation |
|---|---|---|---|
| **RATISS-X** | LLM Mixer | Contribution-guided elite 75% → **5/6 stable** generations | Oracle routing, single prompt specialists |
| **RATISS-VEGA** | Constellation Engine | **Constellation Routing** — multiple GPS centroids coordinating in real-time | *This repo is the complete design blueprint* |

> **Vega** — the brightest star in Lyra. In astronomy, a reference for brightness calibration. In RATISS: our **reference architecture for calibrated, CPU-native intelligence**.

---

## 🎨 Design Philosophy

```
RATISS-X :  one path  →  one expert  →  one token
RATISS-VEGA: constellation of paths → collaborative experts → coherent thought
```

**3 pillars:**

1. **🌀 Constellation Routing** — No single centroid. A dynamic constellation of GPS routers (Question-Specialist, Prompt-Specialist, Contribution-Tracker) votes in <0.2ms.
2. **🧠 Adaptive Mixer Core** — The 75% activation elite from RATISS-X becomes *elastic*: 60%–85% auto-scaling per token complexity.
3. **⚡ Native Vega Engine V3** — BF16 resident + int4 adaptive quantization. Target: **<400 MB RAM, <0.5s/token on 2-core CPU**.
